# RFCs — Request for Comments

Discussão das decisões técnicas relevantes do projeto Mecânica FIAP: contexto, opções
consideradas com prós e contras, recomendação e trade-offs. Um RFC registra o *porquê* de uma
escolha; quando ela vira uma regra arquitetural permanente, há também um [ADR](../adr/).
